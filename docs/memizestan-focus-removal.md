# حذف نمای تمرکز به درخواست کاربر

کاربر گزارش کرد فعال‌کردن نمای تمرکز روی سیستمش چیدمان را خراب کرده است. علت دقیق روی دستگاه او بازتولید نشده؛ این تغییر ادعای تشخیص علت اصلی نیست.

دکمه و نوار تنظیمات، منطق فعال‌سازی و CSS اختصاصی نمای تمرکز حذف شدند. کلید قدیمی hakim.decimals.v1.focusMode هنگام شروع پاک می‌شود و کلاس focus-mode اعمال نمی‌شود. داده‌های بازیکن، نتیجه‌ها و پاسخ‌های نیمه‌کاره دست‌نخورده‌اند. فقط چیدمان عادی واکنش‌گرا باقی مانده است.

آزمون content-layout با کلید قدیمیِ true آغاز می‌شود، حذف تنظیم را بررسی می‌کند و حفظ ۳۰ پاسخ قبلی، نمایش نوار کناری و ابعاد مختلف را کنترل می‌کند. این آزمون، آزمون مرورگری هر ۵۰ تمرین و آزمون کارت‌های مدرسه موفق بودند؛ بررسی نحو و git diff --check نیز موفق بود. کل مجموعهٔ آزمون‌ها در این نوبت دوباره اجرا نشده است.

خروجی مستقل بازسازی شد: exports/memizestan.html، ۲۱۷۱۵۲۸ بایت. کش hakim-v1.5.53.
گزارش قبلیِ content-first-review دربارهٔ نمای تمرکز، تاریخی است و دیگر رفتار جاری بازی را توصیف نمی‌کند. پوش و مرج انجام نشده است.
