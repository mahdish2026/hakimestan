# ابزار دقیق زاویه و کاهش بازسازی گرافیک

## تغییرات
- دکمه‌های افزایش و کاهش یک درجه در تمرین زاویه؛ کنترل مرز صفر و کل زاویه.
- نمایش درشت مقدار، برچسب فارسی دسترس‌پذیر لغزنده، راهنمای صفحه‌کلید و مقیاس دو انتها.
- قاب و رنگ‌بندی اختصاصی ابزار با پشتیبانی از عرض کوچک.
- هنگام حرکت لغزنده، SVG و اجزای آن دوباره ساخته نمی‌شوند. فقط مسیر پرتو، مختصات نوک آن و متن معادله تغییر می‌کند؛ کنترل پاسخ هم‌زمان و بدون تأخیر باقی می‌ماند.
- پس از حل یا آشکارسازی، کنترل‌های جدید نیز قفل می‌شوند.
