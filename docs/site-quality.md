# گزارش آزمون محلی حکیمستان

## چه چیزی سنجیده شد؟

- ۳۸ صفحهٔ HTML ثبت‌شده در گیت: بارگذاری Chromium، خطاهای اجرایی، پاسخ‌های ناموفق محلی، مقصد پیوندهای محلی، عنوان و زبان سند، و عرض محتوای صفحه در ۳۲۰، ۳۹۰ و ۱۲۸۰ پیکسل.
- آزمون اختیاری axe-core با قواعد WCAG A/AA نسخه‌های ۲ و ۲٫۱، روی نمای اولیهٔ هر صفحه در عرض ۳۲۰ با ترجیح کاهش حرکت. نبودن خطای خودکار، گواهی انطباق WCAG نیست.
- آزمون‌های بازی‌ها و ابزارها، از جمله پاسخ‌دهی، بازیابی پیشرفت، جداسازی بازیکن‌ها، گزارش آموزگار، چاپ، ارسال مجدد و حالت آفلاین. سرویس‌های راه‌دور در آزمون‌ها شبیه‌سازی یا مسدود شده‌اند.
- سیاست کش، مانیفست نصب، مقصد میان‌برها، فایل‌های آیکون و تصاویر نصب، و مقصدهای نقشهٔ سایت. آزمون کنتراست مرورگری ۶۴ بررسی موفق داشت.

## اجرای دوباره

گردش‌کار `.github/workflows/site-quality.yml` وابستگی‌های آزمون و دستورات اجرای بررسی سراسری را مشخص می‌کند. برای اجرای محلی، ریشهٔ مخزن را روی `http://localhost:8000/` سرو کنید؛ سپس با وابستگی‌های نصب‌شده و `CHROME_PATH` تنظیم‌شده روی فایل اجرایی Chrome:

```sh
SITE_AXE=1 node tests/site-pages-browser.cjs
node tests/site-metadata.cjs
node tests/sw-cache-policy.cjs
```

زمان‌های چاپ‌شده در آزمون مرورگر صرفاً نمونه‌های بارگذاری محلی هستند، نه سرعت روی اینترنت کاربران. آزمون‌ها روی نسخهٔ میزبانی‌شده، Safari/iOS، Firefox، گوشی واقعی و صفحه‌خوان انسانی انجام نشده‌اند. اعمال هدرهای امنیتی، مجوزهای سمت سرور، دسترس‌پذیری و ظرفیت سرویس‌های آنلاین و Core Web Vitals واقعی نیاز به ارزیابی محیط انتشار دارند.
