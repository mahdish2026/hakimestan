# بازبینی تکمیلی تعامل مهارت‌ها

- ایراد نقاله: پس از تأیید هم‌راستایی، تغییر جهت قبلاً مرحلهٔ خواندن را در رابط باز می‌گذاشت (اعتبارسنج پاسخ جهت غلط را رد می‌کرد). اکنون تغییر جهت مرحله را به هم‌راستایی بازمی‌گرداند، ورودی پاسخ/بررسی را می‌بندد و تأیید دوباره لازم است. پاسخ قبلی حفظ می‌شود.
- جدول مقایسه: پس از بررسی، خانه‌های غلط یا خالی با aria-invalid و حاشیه مشخص می‌شوند؛ بازخورد تعداد خانه‌های نیازمند بازبینی را می‌گوید و با aria-describedby به ورودی‌ها متصل است.
- متن زندهٔ ورودی هنگام بازسازی کنترل‌ها escape می‌شود؛ علاوه بر اعتبارسنجی پیش‌نویس ذخیره‌شده. آزمون متن شامل تگ و کوتیشن ثابت می‌کند عنصر HTML ساخته نمی‌شود.
- نام دسترس‌پذیر گروه از «مهارت‌های تکمیلی» به «مهارت‌های اصلی فصل» اصلاح شد.

هفت مجموعهٔ مرتبط پس از اصلاح و ساخت فایل مستقل موفق بودند: required-skills، chapter-skills، browser (۴۸ تمرین اصلی)، portable، service-worker، accessibility و school-cards. لاگ‌ها: reports/skills-followup/results.txt. نحو و git diff --check موفق. اجرای کامل ۴۷ مجموعه مربوط به نوبت قبل است، نه پس از این تغییر.
