# حکیمستان — دیار حکیم، سرزمین یادگیری

پلتفرم آموزشی رایگان و آفلاین‌پذیر برای دانش‌آموزان و معلمان پایهٔ پنجم ابتدایی.
تمام محتوا با HTML، CSS و JavaScript خالص ساخته شده و روی هر مرورگری اجرا می‌شود.

---


### ابزارهای اصلاح و بررسی

```bash
# سازگاری CSS: پیشوند -webkit- و فالبک color-mix برای مرورگرهای قدیمی‌تر
node tools/css-compat.mjs [--dry]

# لایهٔ اصلاح کنتراست WCAG (فقط موارد قطعی؛ طرح اصلی دست‌نخورده می‌ماند)
node tools/gen-contrast-layer.mjs [--dry]

# گزارش کنتراست همهٔ جفت‌رنگ‌ها
node tools/check-contrast.mjs [--verbose]

# خروجی‌های base64 را به فایل تبدیل کن
node tools/extract-inline-assets.mjs [--dry]

# سیاست امنیت محتوا (CSP) را به همهٔ صفحه‌ها تزریق کن
node tools/inject-csp.mjs [--dry]
```

هر چهار ابزار **idempotent** هستند — اجرای دوباره تغییری ایجاد نمی‌کند.

### لایه‌های تزریق‌شده در هر صفحه

| نشانه | کار |
|---|---|
| `<!-- hakim-core:start -->` | هستهٔ مشترک: CSS دسترس‌پذیری، JS امنیت/PWA/دسترس‌پذیری، manifest |
| `<!-- hakim-contrast:start -->` | اصلاح‌های کنتراست WCAG (فقط صفحه‌های نیازمند) |
| `<!-- hakim-csp:start -->` | سیاست امنیت محتوا در خود صفحه (مستقل از میزبان) |

هر دو با اجرای دوبارهٔ ابزار مربوطه بازنویسی می‌شوند و دستی ویرایش نمی‌شوند.

## اجرا

فایل‌ها کاملاً ایستا هستند:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```

> برای کارکرد درست Service Worker و نصب PWA، صفحه باید از طریق HTTP/HTTPS
> باز شود، نه با `file://`.

---

## امکانات فنی

- **PWA:** نصب روی گوشی و رایانه، کارکرد آفلاین، میان‌برهای سریع
- **دسترس‌پذیری:** پشتیبانی صفحه‌خوان، لینک پرش، کنتراست بالا،
  کاهش انیمیشن، مقیاس متن (۹۰٪ تا ۱۶۰٪)
- **امنیت:** پاک‌سازی ورودی، توکن CSRF، سیاست امنیت محتوا، هدرهای سخت‌گیرانه
- **آفلاین:** تمام بازی‌ها و ابزارها بدون اینترنت کار می‌کنند
- **بدون وابستگی اجرایی:** فایل‌های CDN فقط برای فونت و دو کتابخانهٔ کمکی‌اند

## پیش‌نمایش

ساختهٔ مهدی شریفیان · ۱۴۰۵

### ممیزستان — عددهای اعشاری ریاضی پنجم

بازی `games/math-decimals.html` از مدرسهٔ ریاضی در دسترس است: ۱۰ ایستگاه، ۶۰ تمرین، ابزار صدم‌ها و ارزش مکانی، محور بزرگ‌شونده، پرش و مساحت ضرب؛ ذخیرهٔ محلی پیشرفت (بدون فایل پشتیبان) و گواهی. ۱۰ راهنمای صوتی آماده با صدای مرد فارسی ایران و متن همراه دارد؛ چهار تمرین جمع و تفریق شامل کارگاه عملیِ مرتبه‌به‌مرتبه‌اند. بازخورد اکنون **تشخیصی** است: ۹ قاعدهٔ خطا (جابه‌جایی ممیز، هم‌ترازی، برابری صفرها، واحد، گردکردن، حذف رقم و…)، تمرین خرد جبرانی و دفتر بدفهمی؛ هر ۱۴ تمرین گزینه‌ای برای تک‌تک گزینه‌ها دلیل خطای جدا دارد. دفتر معلم `games/math-decimals-teacher.html` همین داده‌های محلی را به کارت‌های کلاس، جدول دانش‌آموز، بدفهمی‌ها و CSV/چاپ تبدیل می‌کند. برای سنجش کلاسی، `assessment/decimals-check.html` با کلید ۲۰ سؤالی آماده است. نقشهٔ سفر مکعب ایزومتریک و کارت پایانی گواهی دارد و هر درس یک **برج مرتبه‌های سه‌بعدی** (یکان، دهم، صدم، هزارم) با توضیح تعاملی باز می‌کند؛ کارت عدد با حرکت نشانگر عمق می‌گیرد و روی دستگاه لمسی/کاهش حرکت خاموش می‌شود. بالای هر پاسخ عددی نوشته شده که **ممیز را با «٫» یا نقطه** بنویسد و خط کسری «/» پذیرفته نمی‌شود؛ یک **صفحه‌کلید عددی اختیاری** با دکمهٔ ممیز هم زیر کادر باز و بسته می‌شود، بدون آنکه تایپ با کیبورد فیزیکی را جایگزین کند. دور پنجم ظاهر بازی را به «سفر به سیارهٔ ممیزها» برد: جلد داستانی و شفق متحرک، گنجینهٔ ۱۰ گوهر، ستارهٔ پیشرفت هر سیاره، برجسته‌شدن ایستگاه بعدی، برگهٔ مأموریت رنگی، جشن پاسخ درست و مدال پایان سیاره. این پاداش‌ها از پیشرفت واقعی محاسبه می‌شوند و زمان‌سنج یا جدول رده‌بندی ندارند. عبارت‌های عددی و دنباله‌های الگو در جعبهٔ چپ‌به‌راست جدا می‌شوند تا در جملهٔ فارسی جابه‌جا نشوند.

```bash
node tools/build-memizestan.cjs    # exports/memizestan.html، خروجی مستقل
node tests/math-decimals.cjs
# با سرور محلی روی 8000 و Chromium آماده:
node tests/math-decimals-browser.cjs
node tests/math-decimals-diagnosis.cjs
node tests/math-decimals-teacher.cjs
node tests/math-decimals-assessment.cjs
node tests/math-decimals-art3d.cjs
node tests/teacher-panel-math-decimals.cjs  # اتصال بازی به پنل معلم (شبیه‌سازی‌شده)
```
