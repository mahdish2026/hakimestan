# حکیمستان — دیار حکیم، سرزمین یادگیری

پلتفرم آموزشی رایگان و آفلاین‌پذیر برای دانش‌آموزان و معلمان پایهٔ پنجم ابتدایی.
تمام محتوا با HTML، CSS و JavaScript خالص ساخته شده و روی هر مرورگری اجرا می‌شود.

---


### ابزارهای اصلاح و بررسی

```bash
# سازگاری CSS: پیشوند -webkit- و فالبک color-mix برای مرورگرهای قدیمی‌تر
node tools/css-compat.mjs [--dry]

# لایهٔ اصلاح کنتراست WCAG (فقط موارد قطعی؛ طرح اصلی دست‌نخورده می‌ماند)
node tools/gen-contrast-layer.mjs [--dry]

# گزارش کنتراست همهٔ جفت‌رنگ‌ها
node tools/check-contrast.mjs [--verbose]

# خروجی‌های base64 را به فایل تبدیل کن
node tools/extract-inline-assets.mjs [--dry]
```

هر چهار ابزار **idempotent** هستند — اجرای دوباره تغییری ایجاد نمی‌کند.

### لایه‌های تزریق‌شده در هر صفحه

| نشانه | کار |
|---|---|
| `<!-- hakim-core:start -->` | هستهٔ مشترک: CSS دسترس‌پذیری، JS امنیت/PWA/دسترس‌پذیری، manifest |
| `<!-- hakim-contrast:start -->` | اصلاح‌های کنتراست WCAG (فقط صفحه‌های نیازمند) |

هر دو با اجرای دوبارهٔ ابزار مربوطه بازنویسی می‌شوند و دستی ویرایش نمی‌شوند.

## اجرا

فایل‌ها کاملاً ایستا هستند:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```

> برای کارکرد درست Service Worker و نصب PWA، صفحه باید از طریق HTTP/HTTPS
> باز شود، نه با `file://`.

---

## امکانات فنی

- **PWA:** نصب روی گوشی و رایانه، کارکرد آفلاین، میان‌برهای سریع
- **دسترس‌پذیری:** پشتیبانی صفحه‌خوان، لینک پرش، کنتراست بالا،
  کاهش انیمیشن، مقیاس متن (۹۰٪ تا ۱۶۰٪)
- **امنیت:** پاک‌سازی ورودی، توکن CSRF، سیاست امنیت محتوا، هدرهای سخت‌گیرانه
- **آفلاین:** تمام بازی‌ها و ابزارها بدون اینترنت کار می‌کنند
- **بدون وابستگی اجرایی:** فایل‌های CDN فقط برای فونت و دو کتابخانهٔ کمکی‌اند

## ابزارهای توسعه

پس از `npm i sharp`:

```bash
node tools/generate-icons.mjs     # آیکون‌های PWA از icon.svg
node tools/optimize-images.mjs    # تبدیل تصاویر به WebP (۶۸٪ کاهش حجم)
node tools/make-screenshots.mjs   # اسکرین‌شات‌های judges.html
node tools/inject-core.mjs        # تزریق لایه‌های مشترک به همهٔ صفحات
node tools/check-contrast.mjs     # بازرسی کنتراست رنگ طبق WCAG
```

برای دیدن گزارش بازرسی دسترس‌پذیری در مرورگر، نشانی را با `?a11y=debug` باز کنید.
