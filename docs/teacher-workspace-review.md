# بازبینی و ارتقای پنل معلم

تاریخ: ۲۰۲۶/۱۱/۲۷  
محدوده: `panels/teacher.html`، ظاهر اختصاصی پنل، دفتر تعبیه‌شده، قرارداد اتصال فعلی و کش پوستهٔ برنامه.

## تغییرات تجربهٔ کاربری

- طراحی تازهٔ اتاق کار معلم با هدر تصویری SVG محلی، کارت‌های آمار، زمان آخرین دریافت موفق و میان‌بر هشت ابزار موجود. هیچ سرویس یا کتابخانهٔ اجرایی تازه‌ای اضافه نشده است.
- حفظ شش پوسته؛ بازتنظیم پوستهٔ نیلی و آبی، فاصله‌ها، کارت‌ها، جدول‌ها و فرم ورود.
- جایگزینی منوی موبایلِ چندردیفی با نوار افقی قابل پیمایش در بالای صفحه؛ همهٔ مقصدها و خروج در دسترس می‌مانند.
- نمایش وضعیت آنلاین بودن **دستگاه**؛ این نشانگر ادعای سلامت سرویس ابری نمی‌کند.
- صفحه‌بندی ۲۵، ۵۰ و ۱۰۰تایی نتایج به‌جای قطع نمایش بعد از ۲۰۰ رکورد. این صفحه‌بندی روی داده‌های دریافتی از API است و محدودیت احتمالی خود API را حذف نمی‌کند.
- مرتب‌سازی بر اساس ترتیب دریافت، تاریخ، نام یا امتیاز؛ فیلتر تکمیل‌شده/ناتمام؛ خلاصهٔ تعداد رکورد، نام یکتا و تکمیل/عدم تکمیل. «نام یکتا» شناسهٔ قطعی شخص نیست.
- JSON و CSV همهٔ رکوردهای نمای فعلی را صادر می‌کنند، نه فقط صفحهٔ جاری. چاپ نیز همهٔ رکوردهای همان نما را موقتاً نمایش می‌دهد و بعد به صفحهٔ قبلی برمی‌گردد.
- امتیاز بازی‌های مختلف الزاماً هم‌مقیاس نیست؛ در گزارش هشدار داده شده و تحلیل تشخیصی یا رتبه‌بندی آموزشی تازه‌ای از جمع آن‌ها ساخته نشده است.
- بهبود کار با صفحه‌کلید: بازی‌ها دکمهٔ واقعی هستند؛ پنجره‌ها نام قابل خواندن، انتقال/بازگردانی فوکوس، گردش Tab و بستن با Escape دارند. لینک پرش به محتوا و رعایت کاهش حرکت هم اضافه شده است.

## اصلاحات امنیت و پایداری

| ایراد مشاهده‌شده | تغییر |
|---|---|
| رشته‌های عددیِ پاسخ سرویس در HTML درج می‌شدند | خروجی فارسی‌سازی هم escape می‌شود؛ شمارش نمودار فقط عدد متناهی می‌پذیرد |
| CSV می‌توانست با نامی مانند `=HYPERLINK(...)` فرمول اجرا کند | محافظ مشترک سلول CSV برای گزارش نتایج و بازدیدها، همراه با حفظ نقل‌قول‌ها |
| درخواست‌ها زمان پایان نداشتند | AbortController و سقف ۲۰ ثانیه؛ پیام خطای ماندگار و قابل فهم |
| پاسخ فیلتر قبلی می‌توانست نتیجهٔ جدید را بازنویسی کند | شناسهٔ ترتیبی درخواست نتایج؛ پاسخ قدیمی کنار گذاشته می‌شود |
| خروج، اطلاعات پنجره‌ها و حافظهٔ دفتر را نگه می‌داشت | لغو درخواست‌ها، افزایش نسل نشست، پاک‌سازی داده‌ها/پنجره‌ها و کش حافظه‌ای دفتر |
| فایل انتخاب‌شده می‌توانست پس از خروج پنجرهٔ ورود داده باز کند | بررسی نسل نشست در callback فایل؛ HQF علاوه بر نشست به بازی فعلی مقید است |
| نام جست‌وجوشده روی دستگاه مشترک ذخیره می‌شد | پیش‌نویس فیلتر فقط بازی و بازه را نگه می‌دارد، نه نام دانش‌آموز |
| دفتر مدیریتی از دادهٔ شخصی `hakimestan_daftar_v1` به‌عنوان fallback استفاده می‌کرد | حذف اشتراک ذخیره‌سازی؛ دفتر مدیریتی فقط در حافظهٔ نشست، از API احراز‌شده خوانده می‌شود |
| شکست ذخیرهٔ ابری دفتر با موفقیت اشتباه گرفته می‌شد | تغییر کش و اعلام موفقیت فقط بعد از پاسخ موفق صریح سرور؛ شکست، فرم و اطلاعات ویرایشی را باز نگه می‌دارد |
| تبدیل تاریخ شمسی صرفاً ۶۲۱ سال اضافه می‌کرد | تبدیل و اعتبارسنجی واقعی با تقویم فارسی Intl؛ روز نامعتبر رد می‌شود |
| واردکردن فایل بدون محدودیت بود | نتیجه: حداکثر ۵ مگابایت/۱۰هزار رکورد؛ سؤال: حداکثر ۲ مگابایت/۲هزار سؤال؛ دفتر: حداکثر ۵ مگابایت؛ کنترل اولیهٔ ساختار و خطای FileReader |
| فایل سؤال خالی می‌توانست جایگزینی همهٔ سؤال‌ها پیشنهاد کند | بدون سؤال معتبر دکمهٔ جایگزینی ساخته نمی‌شود؛ پیش‌نمایش با تعویض بازی پاک می‌شود |
| امتیاز منفی یا بسیار بزرگ نظرسنجی می‌توانست `repeat` را بشکند | تعداد ستاره در بازهٔ صفر تا پنج محدود می‌شود؛ رکوردهای null/غیرشیء کنار گذاشته می‌شوند |
| کلید `__proto__` شمارندهٔ بازدید را مختل می‌کرد | جدول شمارش بدون prototype |

رمز جدید پنل در رابط حداقل ۱۲ کاراکتر می‌خواهد و نمی‌تواند با رمز فعلی یکسان باشد. رمز ورود بدون trim به سرویس ارسال می‌شود تا فاصلهٔ عمدیِ رمز حذف نشود. این اعتبارسنجی رابط، جایگزین سیاست رمز سمت سرور نیست.

### حفظ داده و رفتار حذف

- دادهٔ شخصی دفتر در localStorage پاک یا مهاجرت نمی‌شود؛ نسخهٔ مدیریتی دیگر آن را نمی‌خواند یا بازنویسی نمی‌کند.
- دفتر مدیریتی پس از بستن/تازه‌سازی صفحه دوباره به اتصال احراز‌شده نیاز دارد. برای کار آفلاین از دفتر مستقل یا گزارش محلی ممیزستان استفاده کنید.
- حذف گروهی همچنان قرارداد موجودِ فیلترهای سرور را اجرا می‌کند، نه فقط صفحهٔ فعلی. هنگام تغییر فیلتر اعمال‌نشده یا فعال بودن فیلتر محلی تکمیل، دکمه غیرفعال است. تأیید متنی و هشدار پشتیبان‌گیری باقی مانده و روشن‌تر شده‌اند.
- درخواست نوشتن خودکار تکرار نمی‌شود. لغو/timeout در مرورگر تضمین نمی‌کند عملیاتی که به سرور رسیده لغو شده باشد؛ پیش از تکرار عملیات مخرب یا واردکردن فایل، وضعیت را بازخوانی کنید.
- نسخهٔ Service Worker به `hakim-v1.5.107` ارتقا یافته و CSS جدید و تصویرسازی محلی در پوستهٔ آفلاین ثبت شده‌اند. داده‌های API همچنان خارج از کش Service Worker هستند.

## آزمون‌های اجراشده

تمام endpointهای پنل در آزمون‌ها شبیه‌سازی شده‌اند؛ هیچ اطلاعات واقعی دانش‌آموزی خوانده، نوشته یا حذف نشده است.

```bash
npm install --no-save --package-lock=false jsdom@26 puppeteer-core @sparticuz/chromium
node tests/teacher-workspace.cjs
node tests/teacher-panel-wiring.cjs
node tests/teacher-panel-geometry.cjs
node tests/teacher-panel-math-decimals.cjs
node tests/phase4-teacher-showcase.cjs
node tests/csp-hardening.cjs
node tests/sw-cache-policy.cjs
node tests/site-review-fixes.cjs

# مرورگر واقعی؛ در ترمینال جداگانه سرور را اجرا کنید:
node tools/serve.cjs 8000 0.0.0.0
node tests/teacher-workspace-browser.cjs
```

- آزمون جدید منطقی: ۲۳۷ نتیجه، صفحه‌بندی/مرتب‌سازی/فیلتر، چاپ همهٔ نتایج، تزریق HTML/CSV، ورودی نامعتبر، timeout، پاسخ خارج از ترتیب، شکست ذخیره، جداسازی دفتر، تبدیل تاریخ و خروج هنگام درخواست معلق.
- مرورگر واقعی Chromium: عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل؛ هر شش پوسته، نبود سرریز افقی، صفحه‌بندی، فوکوس/Tab/Escape و خروج. بدون خطای JavaScript در این سناریوها.
- آزمون اتصال موجود برای کسرستان، نقشستان و ممیزستان موفق بود.
- آزمون عمومی ابزارهای معلم/معرفی پروژه، سیاست کش، CSP و اصلاحات عمومی سایت موفق بود.
- تصاویر آزمایشی با نام‌ها و آمار ساختگی در `reports/teacher-workspace/` نوشته می‌شوند؛ این پوشه در Git نیست.
- آزمون قدیمی `phase4-teacher-showcase.cjs` مطابق قرارداد جدید حریم خصوصی اصلاح شد: نام جست‌وجو نباید باقی بماند، و دفتر مدیریتی از پاسخ mock احراز‌شده استفاده می‌کند، نه localStorage دفتر شخصی.

برای اجرای Chromium در محیطی که کتابخانه‌های NSS نصب نیستند، باید وابستگی‌های سیستم مرورگر فراهم شود یا `CHROME_PATH` به مرورگر نصب‌شده اشاره کند. در محیط این بررسی از کتابخانه‌های همراه بستهٔ Chromium و `LD_LIBRARY_PATH` استفاده شد.

## محدودیت‌ها و کارهای سمت سرور

کد استقرار Google Apps Script و پایگاه داده در این مخزن نیست. بنابراین موارد زیر **تأیید یا پیاده‌سازی نشده‌اند**:

1. اعتبارسنجی واقعی همهٔ توکن‌ها، مجوز مدیر/معلم، تفکیک دادهٔ کلاس‌ها و جلوگیری از دسترسی افقی.
2. هش امن رمز، محدودیت تلاش ورود، انقضا/ابطال توکن، ثبت ممیزی و حذف نشست‌های قبلی هنگام تغییر رمز.
3. اعتبارسنجی کامل schema و اندازهٔ payload در سرور؛ این کنترل‌های مرورگر قابل دور زدن‌اند.
4. کنترل هم‌زمانی/نسخهٔ دفتر در `tpClassSaveAll`؛ ذخیرهٔ هم‌زمان دو دستگاه همچنان به راهکار سمت سرور نیاز دارد.
5. پشتیبان‌گیری خودکار پایگاه داده، بازیابی واقعی و دسترس‌پذیری استقرار زنده.
6. CSP پروژه هنوز برای اسکریپت‌های inline به `unsafe-inline` نیاز دارد. حذف آن مستلزم بیرونی‌سازی اسکریپت‌ها یا سیاست hash/nonce و هماهنگی با ابزار تولید CSP و میزبان است.

این تغییرات بهبود قابل‌آزمون رابط و مرزهای اعتماد مرورگر هستند، نه گواهی امنیت کامل سامانه. اجرای سرویس واقعی در محیط این بررسی محدود بود؛ آزمون تولیدی باید در استقرار واقعی و با حساب آزمایشی انجام شود.


## تکمیل زبان بصری «استودیوی تدریس»

این مرحله ظاهر پنل را با استودیوی گفتگوی پیام‌رسان هم‌خانواده کرده است، بدون حذف مقصدها یا ساختن دادهٔ نمایشی در کد اجرایی:

- زمینهٔ روشن یاسی، کارت‌های سفید، رنگ مکمل سبز مریم‌گلی و هلویی؛ پوستهٔ `blue` پیش‌فرض بازدید تازه است و انتخاب ذخیره‌شدهٔ شش پوسته حفظ می‌شود. `indigo` همچنان گزینهٔ تاریک است.
- تصویر اختصاصی محلی `assets/teacher/learning-garden.svg` با کتاب/جوانه، هم در ورود و هم در هدر داشبورد؛ بدون وابستگی شبکه، فونت یا کتابخانهٔ تازه.
- ورود تصویری، هویت حکیمستان، خوش‌آمد شخصی با نام پاسخ ورود و پاک‌سازی نام هنگام خروج؛ مسیر بازگشت لابی از خود هویت صفحه در دسترس است.
- کارت اصلی بنفش، سلسله‌مراتب روشن تیتر/آمار/رتبه‌ها/میز ابزار و توضیح دقیق معنای داده‌ها. هیچ آمار ساختگی به صفحهٔ تولید اضافه نشده است.
- نمودار ده بازی پرتکرار با HTML و `role=meter`، برچسب قابل خواندن، عدد معتبر/متناهی، مرتب‌سازی نزولی و طول نوار نسبی؛ ورودی منفی به صفر محدود و HTML نام بازی escape می‌شود.
- همراه حکیم دیگر خودکار روی گزارش باز نمی‌شود؛ دکمهٔ راهنما، بستن با Escape/دکمه و پاک‌سازی در خروج دارد. راهنمای دکمه‌ای به shared core تغییری نداده است.
- انتخاب‌گر ظاهر نزدیک ابزارهای هدر باز می‌شود؛ با Escape، کلیک بیرون یا تغییر صفحه بسته می‌شود و فوکوس به دکمه برمی‌گردد.
- نسخهٔ موبایل با نوار مقصد افقی، آمار دو ستونی و ابزارهای دو ستونی؛ سرریز تزئین ورود در موبایل مهار شد. چاپ و کاهش حرکت حفظ شدند.

### شواهد نهایی

`teacher-workspace-browser.cjs` در هر پنج عرض ۱۴۴۰/۱۰۲۴/۷۶۸/۳۹۰/۳۲۰ موفق شد: شش پوسته، بارگذاری تصویر، ورود غلط/درست، میانبر بازی‌ها، مقصدهای کاربران/معلم‌ها/آمار/تنظیمات، باز/بسته‌کردن دفتر، راهنمای اختیاری، انتخاب‌گر ظاهر، کاهش حرکت، صفحه‌بندی و پنجرهٔ نتایج، نبود سرریز و خطای JS/فایل محلی مفقود، خروج و پاک‌سازی نام. تصاویر روشن و تاریک در `reports/teacher-workspace/` تولید می‌شوند.

آزمون منطقی نمودار با `null`، شمارش منفی/نامتناهی، ترتیب و طول نوار و نام تزریقی هم اضافه شد. دوازده مجموعهٔ رگرسیون منطقی/ایستا شامل پنل، پیام‌رسان، CSP، cache و phase4 موفق شدند؛ هر دو مجموعهٔ مرورگر پیام‌رسان نیز در تمام پنج عرض موفق بودند. سه آزمون مرورگر محیط‌های کاری و آزمون‌های منطقی تازه به workflow `Site quality` افزوده شدند تا در PR نیز اجرا شوند.

این شواهد از API شبیه‌سازی‌شده‌اند؛ تأیید backend زنده یا استقرار عمومی محسوب نمی‌شوند.

آزمون‌های عمومی CI نیز اجرا شدند: تیتر اصلی یکتا حفظ شد و آزمون کش مدرسهٔ ریاضی به‌جای قفل‌کردن نسخه روی ۱۰۳، همان حداقل نسخهٔ لازم را با پذیرش افزایش‌های معتبر بعدی بررسی می‌کند. آزمون مرورگر شخصیت مشترک پس از ورود آزمایشی، راهنما را با دکمه باز می‌کند و شش پوسته/رنگ/کاهش حرکت/دسترس‌پذیری آن را همچنان می‌سنجد.
